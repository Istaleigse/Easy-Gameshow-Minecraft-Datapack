# Easy Gameshow

**Easy Gameshow** turns a Minecraft world into a easy-to-setup gameshow studio. It is designed for people who want to host a gameshow with friends without needing to know Minecraft commands or how datapacks work.

## What is Easy Gameshow?

Easy Gameshow is a party gameshow for **four players**. The players take part in challenges, but the most important part is not simply being the fastest or best at a task: it is knowing what you and the other players are capable of.

For example:

> How many blocks can you travel in one direction within a set amount of time?

Each player secretly writes down what they think they can achieve. The host then reveals the answers in the studio.

The player whose estimate is best placed has to attempt the challenge. If they achieve the target they predicted, they earn points. If they do not, players with the next-best estimates can receive fewer points.

This means players have to balance confidence with realistic expectations. Overestimating yourself can be risky, but underestimating everyone else can be risky too.

## Getting started

### 1. Download and install

1. Download the Easy Gameshow ZIP file.
2. **Extract** the ZIP file.
3. Open the extracted folders. Depending on how the ZIP was packaged, the actual datapack may be inside an additional folder.
4. Find the folder that contains the file **`pack.mcmeta`**. **That is the actual datapack folder you need.**
5. Open the folder of the Minecraft world in which you want to play, then open that world's `datapacks` folder.
6. Move the folder containing `pack.mcmeta` directly into `datapacks`.

Your folder structure should look like this:

```text
<your-world>/
└── datapacks/
    └── Gameshow/
        ├── pack.mcmeta
        └── data/
```

The folder name may be different, but the important thing is that `pack.mcmeta` is directly inside the folder you place in `datapacks`.

**Important:** Do not put the ZIP file itself into `datapacks`. Also, do not copy an outer download or wrapper folder if `pack.mcmeta` is one level deeper. Open folders until you find `pack.mcmeta`, then move the folder containing that file into `datapacks`.

### 2. Load the datapack

After installing it, either:

- restart your Minecraft server, or
- run `/reload` in the server console or in-game (as an operator).

When the datapack has loaded, it will display an information message in chat. Use the clickable option in that message to get started.

## Setting up your gameshow

You do not need to enter commands or know how the datapack is built. The gameshow is controlled with in-game items and clickable menus.

### Setup item

Use the Setup item to prepare the studio. You can choose where important parts of the gameshow should be placed, for example:

- the main board in the studio;
- the individual challenge boards;
- the participants' seats;
- other locations needed for the gameshow.

The setup is done in-game by selecting the relevant locations.

### Gamecontrol item

Use the Gamecontrol item to guide the host through the gameshow. It is intended to take you through the different stages of a round, so you can manage the show from the studio instead of remembering commands.

## The aim of the game

The aim is to understand yourself and the other players:

- **Do not overestimate yourself:** a high target may be difficult to achieve.
- **Do not underestimate yourself:** a realistic but confident estimate can pay off.
- **Read the other players:** their estimates can be just as important as your own.

The winner is not necessarily the player who is best at every challenge. It is the player who makes the smartest estimates and performs when it matters.
